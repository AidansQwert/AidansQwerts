LINUX ON ANDROID 101

2026-09-20 · BASICS · 6 MIN READ

Android is Linux — it just hides the parts you want. Every "Linux on Android" app is really answering one question: how do we get a normal userland running on a kernel that was never meant to host one? There are two honest answers, and picking the wrong one is why people say it's slow.

Option 1 — PRoot (no root)

PRoot fakes a root filesystem in userspace. It attaches to your processes with ptrace and rewrites path-related syscalls on the fly, so /usr inside the container maps to a folder in Termux's data directory. Nothing privileged happens, which is exactly why it works without root.

The cost: every intercepted syscall takes a detour through PRoot. File-heavy work — apt, compiling, git on a big repo — is where you feel it.

Good for: shells, Python, Node, light dev, learning. Bad for: systemd, Docker, anything that expects real process isolation.

Option 2 — real namespaces (root)

With root you can use what the kernel already has: mount, PID, UTS, IPC and network namespaces plus cgroups. The container is a genuine isolated environment and code runs at native speed, because nothing is being traced.

That's the path AetherBox takes — a tiny static binary that sets up the namespaces and then gets out of the way. Init systems boot, services start, systemctl means something again.

How to choose in 30 seconds

  • Not rooted, don't want to be → PRoot via proot-distro or AetherBox Lite.
  • Rooted with Magisk/KernelSU/APatch → the root edition, no contest.
  • Need systemd, Docker, or heavy compiles → root only.
  • Under 4GB free storage → stay CLI-only whichever path you take.

Try the no-root path right now

TERMUX
pkg update -y && pkg install -y proot-distro
proot-distro install debian
proot-distro login debian

Things that bite beginners

  • Play Store Termux. It's frozen in time and package installs fail. Use F-Droid.
  • Battery optimisation. Android will kill a long build. Set the app to unrestricted.
  • Storage math. A desktop session is 6–8GB, not 2GB. Check before downloading.
  • Expecting GPU acceleration. Mostly software rendering; don't plan on gaming.
