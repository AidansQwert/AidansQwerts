INSTALL GUIDE

Two paths: rooted (full AetherBox, native containers) or no root (AetherBox Lite through Termux). Pick one, follow the steps in order, and read the FAQ at the bottom before opening an issue.

// PATH A — ROOTED DEVICE

AetherBox (root)

Check your root setup

Open Magisk / KernelSU / APatch and confirm root is active. Android 8+ and kernel 4.x or newer.

Download the APK

Grab the latest release straight from GitHub — never from a mirror site.

↓ LATEST RELEASE ↗
Install and grant root

Install the APK, open it, and accept the root prompt. If no prompt appears, grant it manually in your root manager.

OPTIONAL · SIDELOAD VIA ADB
adb install -r AetherBox.apk
Pick a rootfs

Go to Distros, choose Debian / Ubuntu / Arch / Alpine and let it download and unpack. Keep the screen on for the first unpack.

Start the container

Hit start, then open the shell. Set a password and update packages before anything else.

INSIDE THE CONTAINER
apt update && apt upgrade -y
apt install -y sudo nano openssh-server
passwd
Optional: desktop session

Install XFCE plus a VNC server inside the container, then connect from any VNC viewer on the phone.

XFCE + VNC
apt install -y xfce4 xfce4-goodies tigervnc-standalone-server
vncserver :1 -geometry 1280x720 -localhost no
// PATH B — NO ROOT

AetherBox Lite / Termux

Install Termux from F-Droid

The Play Store build is outdated and breaks package installs. Use F-Droid or the GitHub release.

Prepare Termux
TERMUX
pkg update -y && pkg upgrade -y
pkg install -y proot-distro git wget
termux-setup-storage
Install a distro
PROOT-DISTRO
proot-distro install debian
proot-distro login debian
Install the Lite APK

It gives you the same Home · Distros · Panel UI on top of the Termux setup.

↓ LITE RELEASE ↗
Optional: Omarchy desktop

Heavy but pretty — needs about 8GB free storage and patience on the first boot.

// WHEN IT BREAKS

Common errors

"permission denied" on start

Root was never granted. Revoke and re-grant AetherBox in Magisk/KernelSU, then force-stop and reopen the app.

Container starts then dies

Usually battery optimisation killing the process. Set the app to unrestricted in Android battery settings.

cgroup errors on old kernels

Kernel 4.x needs the Cgroup V1 fallback — it is automatic, but disable any custom cgroup tweaks from other modules.

Unpack fails halfway

Out of storage or the download got truncated. Free up space, delete the partial rootfs, download again.

Termux: "unable to locate package"

Play Store Termux. Uninstall it and install the F-Droid build, then run pkg update again.

VNC shows a grey screen

The desktop session never started. Check ~/.vnc/*.log and make sure xfce4 is installed inside the container.

// FAQ

Questions people actually ask

Does AetherBox need root?
The main app does — Magisk, KernelSU or APatch. No root? Use AetherBox Lite, which runs Linux through Termux and proot-distro instead.
Which distros can I run?
Debian, Ubuntu, Arch, Alpine, Fedora, Void and other images from the curated rootfs repository — on aarch64, armhf, x86_64, x86 and riscv64.
Can I run a real desktop?
Yes — XFCE, Hyprland via X11 and friends, over X11 or VNC. Budget ~6GB storage and expect the battery to drop faster.
Is Lite slower than the root version?
Yes. PRoot emulates syscalls, so heavy compiling feels noticeably slower. The root edition uses real namespaces and runs at native speed.
Will this brick or harm my phone?
Containers stay isolated from Android, but root always carries risk. Back up your rootfs and don't run scripts you don't trust as root.
Can I use Docker inside a container?
On the root edition with a kernel that ships the needed cgroup and namespace options, yes. On Lite, no — PRoot can't provide what Docker needs.
How do I back up my container?
Export the rootfs from the app before major upgrades, or archive it manually: tar -czf rootfs.tar.gz /path/to/rootfs.
Where do I report a bug?
Open an issue on the AetherBox repo with your device, Android version, kernel and root manager — or ping me on the contact page.
