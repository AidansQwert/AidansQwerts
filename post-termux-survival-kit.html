TERMUX SURVIVAL KIT

2026-08-30 · TERMUX · 5 MIN READ

Every time I get a new phone I run roughly the same twenty minutes of setup. Here it is, in order, so I stop rewriting it from memory.

0. Get the right Termux

F-Droid or the GitHub release. The Play Store build is years old and its repos are dead — 90% of "unable to locate package" posts are this.

1. Base packages

BASE
pkg update -y && pkg upgrade -y
pkg install -y git curl wget nano openssh tmux zsh proot-distro
termux-setup-storage

2. SSH in from a laptop

Typing on glass is misery. Run sshd on the phone and connect over Wi-Fi — Termux uses port 8022.

ON THE PHONE
passwd
sshd
ifconfig | grep inet
ON THE LAPTOP
ssh -p 8022 u0_a123@192.168.1.x

Your username is whatever whoami prints in Termux.

3. Stop Android from killing your session

  • Battery settings → Termux → Unrestricted.
  • Enable the acquire wakelock action from the Termux notification for long builds.
  • Lock Termux in the recents list on OEM skins that aggressively clean it.
  • Use tmux so a dropped session doesn't kill the job.

4. Make the shell pleasant

ZSH + EXTRA KEYS
chsh -s zsh
mkdir -p ~/.termux
printf 'extra-keys = [["ESC","/","-","HOME","UP","END"],["TAB","CTRL","ALT","LEFT","DOWN","RIGHT"]]\n' > ~/.termux/termux.properties
termux-reload-settings

5. Then add a real distro

Once the base is comfortable, install Debian through proot-distro — or go rooted with AetherBox for native-speed containers. Both routes are written up on the guide page.

Backup habit: keep your dotfiles in a git repo. Reinstalling Termux is easy; remembering your own tweaks is not.
