AetherBox
v1.4.0 · latest

A lightweight, LXC-like container runtime for Android and Linux — a community fork of Droidspaces. Full Linux distributions run natively, with zero performance penalty, from a single static binary under 400KB.

  • Full init system support — systemd, OpenRC, runit, s6
  • Native on Android and Linux desktop from the same musl binary
  • Redesigned Android app: curated Rootfs Repository, custom theming
  • Runs in minimal environments too, including Android recovery/ramdisk
