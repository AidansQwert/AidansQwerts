.002 // MY PROJECT

AETHERBOX

AetherBox is my own project — an official fork of Droidspaces (by ravindu644; credit where credit is due). A tiny (<400KB, statically compiled against musl libc) container runtime that runs full Linux distros on top of Android with native performance and zero dependencies. The full app needs root (Magisk / KernelSU / APatch). No root? grab Lite instead.

AetherBox ROOT MINE

latest: v1.4.0 · — · SYNCING
  • Native containers via the droidspaces binary
  • Full init systems: systemd / OpenRC / runit / s6
  • Curated Rootfs Repository + theme builder
  • aarch64 · armhf · x86_64 · x86 · riscv64
  • Works even on kernel 4.x (auto Cgroup V1 fallback)
↓ DOWNLOAD APK GITHUB REPO →

AetherBox Lite NO-ROOT MINE

latest: v0.1.5 · — · SYNCING
  • Companion app for devices without root
  • Installs via Termux — proot-distro or Omarchy
  • Same UI shape: Home · Distros · Panel
  • Theme palettes: Aether / Nebula / Ocean / Graphite / Forest
  • Omarchy desktop needs ~8GB free storage
