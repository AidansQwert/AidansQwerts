AETHERBOX

Run full Linux distros on your Android phone — natively. AetherBox is an official fork of Droidspaces (by ravindu644, credit where credit is due): a container runtime under 400KB, statically compiled against musl libc, zero dependencies. Root edition for real namespaces, or Lite if your device isn't rooted.

Before you install

Root edition

  • Android 8+ with Magisk, KernelSU or APatch
  • Kernel 4.x or newer (cgroup v1 or v2)
  • ~2GB free storage for a CLI distro
  • ~6GB+ if you want a desktop session

Lite (no root)

  • Termux from F-Droid or GitHub (not Play Store)
  • Android 7+, any CPU Termux supports
  • ~3GB free storage for Debian via proot-distro
  • ~8GB for the Omarchy desktop

Good to know

  • PRoot is slower — syscalls are emulated
  • Battery drain is real when running a desktop
  • Keep the app excluded from battery optimisation
  • Backups: export the rootfs before big upgrades
// UNDER THE HOOD

What makes it different

Real namespaces, not emulation

The root edition uses Linux namespaces and cgroups directly, so processes run at native speed instead of being traced like PRoot does.

Tiny static binary

Under 400KB, built against musl libc with no runtime dependencies — it drops onto almost any kernel.

Init systems that actually work

systemd, OpenRC, runit and s6 all boot inside a container, so services like SSH or Docker behave normally.

Desktop sessions

XFCE, Hyprland via X11, and other environments run over VNC or a local X server.
